Migrasi Google Apps Script ke MySQL

Panduan lengkap migrasi sistem presensi RFID dari Google Sheets ke database MySQL di Hostinger untuk 1500+ siswa

Mengapa Harus Migrasi?

Google Apps Script dan Google Sheets memiliki keterbatasan yang signifikan ketika menangani data dalam jumlah besar:

Aspek Google Apps Script MySQL + PHP
Waktu Eksekusi Maksimal 6 menit per script Tidak ada limit
Request per Hari 20.000 UrlFetch Unlimited
Kecepatan Query 3-10 detik (1500 data) 0.05 detik (1500 data)
Penyimpanan 10 juta cell Tergantung storage server
⚠️ Peringatan: Apps Script memiliki timeout 6 menit PER EKSEKUSI (bukan per hari). Jika proses rekap 1500 siswa melebihi 6 menit, script akan berhenti di tengah jalan!

Fase 1: Perencanaan Struktur Database

Ubah data flat dari Google Sheets menjadi relational database:

Tabel Siswa

CREATE TABLE siswa ( id INT AUTO_INCREMENT PRIMARY KEY, nis VARCHAR(20) UNIQUE NOT NULL, nama VARCHAR(100) NOT NULL, kelas_id INT, uid_rfid VARCHAR(20) UNIQUE, tanggal_lahir DATE, INDEX idx_nis (nis), INDEX idx_uid (uid_rfid) );

Tabel Presensi

CREATE TABLE presensi ( id INT AUTO_INCREMENT PRIMARY KEY, siswa_id INT NOT NULL, waktu_masuk DATETIME NOT NULL, status ENUM('TEPAT_WAKTU','TERLAMBAT','IZIN','ALPHA'), FOREIGN KEY (siswa_id) REFERENCES siswa(id), INDEX idx_waktu (waktu_masuk) );
💡 Tips Penting: Selalu tambahkan INDEX pada kolom yang sering di-query (nis, uid_rfid, waktu_masuk). Ini mempercepat pencarian hingga 100x!

Fase 2: Pembuatan Database di Hostinger

  1. Login ke hPanel Hostinger
  2. Masuk ke menu Databases → MySQL Databases
  3. Buat database baru dan catat informasinya:
    Database Name : u123456789_presensi
    Username : u123456789_admin
    Password : (password yang dibuat)
    Host : localhost
  4. Buka phpMyAdmin dan jalankan script CREATE TABLE
✅ Verifikasi: Pastikan 4 tabel muncul di panel kiri phpMyAdmin dan struktur kolom sudah sesuai.

Fase 3: Migrasi Data dari Google Sheets

Ekspor dari Google Sheets

File → Download → Comma Separated Values (.csv)

Import ke MySQL

  1. Buka phpMyAdmin → pilih tabel 'siswa'
  2. Klik tab "Import"
  3. Pilih file CSV yang sudah di-download
  4. Pengaturan:
    • Format: CSV
    • Columns separated with: , (koma)
    • ☑ "CSV has column names in first row"
  5. Klik "Go"
️ Penting: Pastikan urutan kolom di CSV sama dengan struktur tabel MySQL!

Fase 4: Membangun Backend API (PHP)

File Konfigurasi Database

<?php
// config/database.php
$host = 'localhost';
$db   = 'u123456789_presensi';
$user = 'u123456789_admin';
$pass = 'password_anda';

$pdo = new PDO(
    "mysql:host=$host;dbname=$db;charset=utf8mb4",
    $user, $pass,
    [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]
);
?>

Endpoint Presensi dengan Logika Waktu

<?php
// api/presensi.php
require_once '../config/database.php';

header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');

$uid = $_POST['uid'] ?? null;

// Cek waktu (06:30 - 07:06)
$sekarang = new DateTime();
$jam = (int)$sekarang->format('H');
$menit = (int)$sekarang->format('i');
$waktuMenit = ($jam * 60) + $menit;

$batasMulai = (6 * 60) + 30;  // 06:30
$batasAkhir = (7 * 60) + 6;   // 07:06

if ($waktuMenit < $batasMulai || $waktuMenit > $batasAkhir) {
    echo json_encode([
        'status' => 'failed',
        'pesan' => 'Di luar jam presensi'
    ]);
    exit;
}

// Cek dan simpan data
$stmt = $pdo->prepare("SELECT id, nama FROM siswa WHERE uid_rfid = ?");
$stmt->execute([$uid]);
$siswa = $stmt->fetch();

if (!$siswa) {
    echo json_encode(['status' => 'failed', 'pesan' => 'UID tidak terdaftar']);
    exit;
}

$status = ($waktuMenit <= 420) ? 'TEPAT_WAKTU' : 'TERLAMBAT';

$stmt = $pdo->prepare("INSERT INTO presensi (siswa_id, waktu_masuk, status) VALUES (?, NOW(), ?)");
$stmt->execute([$siswa['id'], $status]);

echo json_encode([
    'status' => 'success',
    'pesan' => 'Presensi berhasil',
    'nama' => $siswa['nama']
]);
?>

Fase 5: Penyesuaian Frontend & RFID

Perubahan di Frontend JavaScript

// SEBELUM (Apps Script):
google.script.run.withSuccessHandler(tampilkan).getDataSiswa();

// SESUDAH (Fetch API):
fetch('https://domainanda.com/api/siswa.php?page=1')
.then(res => res.json())
.then(data => tampilkan(data.data));

Perubahan di Alat RFID (ESP8266/ESP32)

void kirimPresensi(String uid) {
  HTTPClient http;
  http.begin("https://domainanda.com/api/presensi.php");
  http.addHeader("Content-Type", "application/x-www-form-urlencoded");
  
  String postData = "uid=" + uid;
  int httpCode = http.POST(postData);
  
  if (httpCode == 200) {
    String response = http.getString();
    // Jika "success" → BEEP 1x, LCD: "Hadir"
    // Jika "failed"  → BEEP 3x, LCD: "Ditolak"
  }
  http.end();
}

Fase 6: Deploy ke Hostinger

Upload File

  1. Masuk ke hPanel → Files → File Manager
  2. Navigasi ke folder public_html/
  3. Upload struktur folder:
    public_html/ ├── config/database.php ├── api/presensi.php ── api/siswa.php └── index.html

Aktifkan SSL (WAJIB!)

  1. hPanel → Advanced → SSL
  2. Install Let's Encrypt (Gratis)
  3. Aktifkan "Force HTTPS"
⚠️ Penting: Tanpa HTTPS, browser akan memblokir request API dari alat RFID!

Amankan Folder Config

Buat file .htaccess di folder config/:

Deny from all

Troubleshooting

Masalah Solusi
500 Internal Server Error Cek Error Logs di hPanel → Advanced
Access Denied Database Pastikan Host = localhost (bukan IP)
CORS Error Tambahkan header Access-Control-Allow-Origin
RFID tidak kirim data Pastikan domain sudah HTTPS
Koneksi lambat Tambahkan INDEX pada kolom penting

Checklist Final

  • Struktur tabel sudah dibuat di phpMyAdmin
  • Data dari Sheets sudah di-import
  • INDEX sudah ditambahkan di kolom penting
  • File database.php sudah diisi kredensial Hostinger
  • Semua endpoint API sudah dites (GET, POST)
  • Logika waktu presensi sudah sesuai (06:30 - 07:06)
  • SSL/HTTPS sudah aktif
  • Force HTTPS sudah di-enable
  • Folder config/ dilindungi .htaccess
  • Alat RFID sudah di-update endpoint-nya ke HTTPS
