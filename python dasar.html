Python Dasar

Pengenalan bahasa pemrograman Python yang mudah dipelajari, mulai dari variabel, tipe data, hingga percabangan sederhana.

Apa itu Python dan Variabel?

Python adalah bahasa pemrograman tingkat tinggi yang terkenal karena sintaksnya yang mudah dibaca dan serbaguna. Sangat cocok untuk pemula.

Variabel adalah tempat atau wadah untuk menyimpan data di dalam memori komputer. Di Python, kita tidak perlu mendeklarasikan tipe data secara eksplisit.

nama = "Budi" umur = 15 tinggi = 165.5
Contoh:
Pada kode di atas, nama menyimpan teks (string), umur menyimpan angka bulat (integer), dan tinggi menyimpan angka desimal (float).

Tipe Data Dasar

Dalam Python, terdapat beberapa tipe data dasar yang sering digunakan:

  • Integer (int): Angka bulat (contoh: 10, -5)
  • Float: Angka desimal (contoh: 3.14, 2.5)
  • String (str): Teks yang diapit tanda kutip (contoh: "Halo", 'Python')
  • Boolean (bool): Nilai kebenaran, hanya bernilai True atau False

Operasi Aritmatika

Python dapat digunakan seperti kalkulator untuk melakukan perhitungan matematika dasar.

+ : Penjumlahan - : Pengurangan * : Perkalian / : Pembagian ** : Pemangkatan % : Modulo (Sisa bagi)
Contoh:
hasil = 10 + 5 (hasilnya 15)
sisa = 10 % 3 (hasilnya 1, karena 10 dibagi 3 sisa 1)

Percabangan (If-Else)

Percabangan digunakan untuk membuat keputusan dalam program berdasarkan kondisi tertentu. Python menggunakan indentasi (spasi) untuk menandai blok kode.

nilai = 80 if nilai >= 75: print("Lulus") else: print("Tidak Lulus")
Contoh:
Karena nilai (80) lebih besar dari atau sama dengan 75, maka program akan mencetak "Lulus" ke layar.

Latihan Soal

Uji pemahamanmu dengan tantangan coding berikut:

  1. Buatlah dua variabel: nama (isi dengan namamu) dan umur (isi dengan umurmu), lalu tampilkan menggunakan fungsi print().
  2. Tulis kode Python untuk menghitung luas persegi panjang dengan panjang 10 dan lebar 5, lalu simpan hasilnya dalam variabel luas.
  3. Buat program sederhana menggunakan if-else untuk mengecek apakah sebuah angka (misalnya 7) adalah bilangan genap atau ganjil (gunakan operator modulo %).
